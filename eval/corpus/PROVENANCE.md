# Corpus provenance

This file is the only place in the repository that names the writers behind the eval personas. Prompts, skills, reports, and file names use persona IDs only, so the model cannot lean on a known author.

Every document in `eval/corpus/<persona-id>/` has one row below: file, source URL, title or section, date, license, word count, and attribution text. Each persona section states the license evidence (where the license text was found and when it was checked) and the changes made to every document of that persona. The licenses are summarized in `LICENSE-CORPUS.md`.

How the files were made: `eval/sourcing/build_corpus.py` fetched each source, checked its license on the page itself, and wrote the cleaned text; `eval/sourcing/build_report.json` is its machine-readable record. The per-document tables between the `docs:` markers are written by `eval/sourcing/make_provenance.py` from that report. Licenses were checked on 2026-10-20.
